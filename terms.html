Personal Volvo Telemetry – Terms and Conditions

Last updated: 17 November 2026

1. What this application is

Personal Volvo Telemetry is a private, non-commercial application operated by the owner of this repository for use with their own vehicle. It is not offered to the public.

2. Data accessed

With your consent given through Volvo ID, the application reads vehicle status data (such as odometer, fuel or battery level, tyre, door, window and lock status, warnings, diagnostics and trip statistics) and the vehicle's last known location. The application only reads data. It does not lock, unlock, start or otherwise control the vehicle.

3. How data is used and stored

Data is stored only on infrastructure controlled by the application owner (a self-hosted Prometheus/Grafana instance and local database) for personal monitoring and history. Data is not sold, shared with third parties or used for advertising.

4. Retention and deletion

Data is kept for as long as it is useful for personal monitoring and can be deleted at any time by the owner. Access can be revoked at any time in your Volvo ID account, after which no further data is collected.

5. Liability

The application is provided as is, without any warranty. Vehicle data may be delayed or inaccurate and must not be relied on for safety-critical decisions.

6. Volvo terms

Use of Volvo Cars APIs is also subject to the Volvo Cars Developer Portal and API terms and conditions.
